# Пауза / MindPause

«Пауза» помогает прерывать долгий просмотр ленты короткими учебными заданиями. Выберите, например, TikTok и интервал в пять минут. Когда наберётся пять минут активного просмотра, приложение откроет задачу. Если выйти из ленты или заблокировать телефон, таймер подождёт.

[Скачать APK для Android 8 и новее](https://github.com/NickSunRiSe/MindPause/releases/download/v0.5.0/pause-0.5.0.apk) · [Инструкция по установке](docs/INSTALL.md) · [Все выпуски](https://github.com/NickSunRiSe/MindPause/releases)

## Первые пять минут

1. Установите APK. Если основная «Пауза» уже стоит на телефоне, выберите «Обновить», чтобы сохранить настройки.
2. Откройте «Паузу», нажмите «Выбрать приложения» и отметьте нужные.
3. Нажмите «Включить доступ». В специальных возможностях Android включите службу «Пауза — перерывы на задачи» и вернитесь в приложение.
4. Откройте выбранную ленту. По умолчанию перерыв наступает через пять минут активного просмотра. Для пробы можно сразу нажать «Пробный перерыв».

## Что можно настроить

- **Приложения.** Для каждого можно выбрать интервал, число задач за перерыв, количество пропусков и задержку перед пропуском. Доступно общее расписание по времени и дням недели.
- **Предметы.** Математика, русский, английский, история, география и память. У каждого свой уровень и способ ответа — ввод с клавиатуры, выбор из вариантов или чередование. Математические задачи и последовательности для запоминания генерируются. В остальных четырёх предметах 1231 задание. [Состав банка и источники](docs/QUESTION_BANK.md)
- **Разбор.** Можно взять подсказку или посмотреть правильный ответ с объяснением. После разбора приложение предлагает новую задачу, пропуск за счёт дневной квоты или выбор между ними. Разбор учитывается отдельно от самостоятельного решения.
- **Дневной лимит просмотра.** Задаётся в минутах для каждого приложения. Когда время заканчивается, «Пауза» предлагает выйти из ленты до следующего дня.
- **Учебная цель.** Задайте число самостоятельных решений на день. После выполнения цели обычные перерывы прекращаются до полуночи, а дневной лимит просмотра продолжает действовать. Обе настройки по умолчанию выключены.
- **Статистика.** Время просмотра показывается по приложениям и в сумме. За выбранный день или весь период можно посмотреть решения, разборы, пропуски, ошибки и среднее время решения по предмету и сложности. Пробные задания в статистику не входят.
- **Оформление и звук.** Интерфейс и задания доступны на русском и английском. Есть светлая, тёмная и системная темы. В дополнительных настройках можно выбрать, приостанавливать ли фоновую музыку на время задачи.

## Доступ и данные

Служба специальных возможностей определяет приложение в активном окне по имени пакета и открывает задачу в нужный момент. Она читает имя пакета корневого узла. Настройки, история решений и время просмотра хранятся на телефоне. Приложение работает без аккаунта и разрешения на интернет. [Код службы](app/src/main/java/app/mindpause/android/FocusService.java) · [Манифест](app/src/main/AndroidManifest.xml)

## Сборка

Нужны JDK 17, Android SDK Platform 36 и Build Tools 35.0.0. Проект можно открыть в Android Studio. Чтобы запустить модульные тесты, Android Lint и собрать отладочный APK, выполните из корня проекта:

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

В Windows используйте `gradlew.bat`. Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`. При желании JDK, SDK и Gradle можно установить в папку проекта командой `./scripts/bootstrap.ps1`, затем собрать приложение командой `./scripts/build.ps1`.

Основной код находится в `app/src/main`, модульные тесты в `app/src/test`, проверки интерфейса в `app/src/androidTest`. Модули `fixture` и `snapshot` используются для проверок на отдельном тестовом эмуляторе. Скрипты таких проверок меняют настройки эмулятора и могут переустанавливать тестовые приложения.
